## OS Commands and Their Uses

* **`strace`** – Traces and displays the system calls and signals generated while a Linux program is running.
* **`open()`** – Used to open an existing file or create a new file for accessing its contents.
* **`read()`** – Retrieves data from an opened file into a buffer.
* **`write()`** – Transfers data from a buffer into an opened file.
* **`close()`** – Closes a file descriptor after the file operations are completed.
