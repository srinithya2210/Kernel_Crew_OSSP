Signals and Signal Handler: -

A signal is a notification sent to a process to indicate that an event has occurred.
Signals are used for communication between the operating system and processes.
A signal handler is a function that handles the received signal.

The program handles three signals: -

SIGINT → Interrupt signal, usually generated by pressing Ctrl+C.
SIGTERM → Termination signal, used to request a process to terminate.
SIGUSR1 → User-defined signal, used for application-specific purposes.
The signal() system call can be used to register a signal handler.
When a signal is received, the registered signal handler executes automatically.
After handling the signal, the process can continue execution or terminate, depending on the signal and handler.

Flow: -

Signal is generated
        ↓
Signal is sent to process
        ↓
Signal handler is called
        ↓
Handler performs the required action
